 Finanças – 2º Bimestre

 Sobre o projeto

Este projeto foi desenvolvido como atividade escolar do 2º bimestre, com o objetivo de apresentar conceitos matemáticos relacionados à educação financeira de forma prática e interativa.

O site permite aprender sobre financiamentos, investimentos, juros compostos e planejamento financeiro.

Funcionalidades

- **Início:** apresentação do projeto.
- **Financiamentos:** simuladores dos sistemas SAC e PRICE, com tabelas e gráficos comparativos.
- **Investimentos:** simulador de renda fixa utilizando juros compostos.
- **Aprenda:** conteúdos explicativos sobre diferentes modalidades de investimentos.
- **Reflexão:** discussões sobre educação financeira e decisões econômicas.
- **Fontes:** referências utilizadas na elaboração do trabalho e identificação dos integrantes.

 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

 Objetivo

Demonstrar como a matemática está presente nas decisões financeiras do cotidiano, ajudando a compreender melhor os juros, os investimentos e os financiamentos.

 Como acessar

O projeto pode ser acessado por meio do navegador, utilizando o link de publicação do site.
